Core Capabilities

一个日历，两种打开方式：用手点，或让模型调。

界面与交互对原站 1:1 还原（CSS 969 行零差异），能力上则从「网页备忘录」升级为「本地日程服务」。

01

完全离线运行

数据落在本地 data/memo.db（SQLite WAL），无任何外部服务依赖。拔掉网线，日历照常翻页。

02

免安装三形态交付

安装包 .exe、免安装 zip（双击即用，无需 Python）、Tauri 桌面版，同一内核三种分发。

03

自然语言建日程

「明天下午3点 评审会 2小时 #项目A 紧急」——规则式解析，确定性输出，返回 source.matched 告知识别了哪些片段；时间不明返回 422，绝不臆造。

04

复杂重复规则

每两周、每月第 2 个星期二、每月最后一个星期五，表单下拉可选，API 直传字符串；月末自动收敛（1/31 → 2/28）。

05

双通道鉴权

浏览器走 Cookie 会话，AI / 脚本 / MCP 走 Bearer Token；同一套 current_user() 统一身份，前端零改动。

06

幂等写入

写接口支持 Idempotency-Key，模型重试不会创建重复日程，同 key 返回首次结果并标记 idempotent: true。

Security & Verification

能被 AI 调用的接口，先把闸门焊死。

相对原站新增的安全加固，全部有实现、有回归测试兜底。

  • HASH
    Token 只存 SHA-256 哈希明文仅签发时返回一次，附带 last_used / use_count 审计，可随时吊销。
  • LOCK
    登录防爆破同账号 + IP 连续 5 次失败锁 15 分钟；密码正确即解锁，不把主人锁在门外。
  • PWD
    密码策略≥8 位、含字母 + 数字、拦截常见弱口令与字符重复。
  • WAL
    并发安全SQLite WAL + busy_timeout，读写不再互斥失败。
  • XSS
    前端转义静态检查innerHTML 转义纳入测试套件，含 JS 语法编译验证。

Quick Start

三步，从解压到模型接入。

普通用户止步于第二步；想让 Claude / Cursor 接管日程的开发者，多一步签发 Token。

STEP 01

解压并启动

双击日历备忘录.exe，本地服务自动运行在 8000 端口并打开浏览器。

日历备忘录.exe
STEP 02

设置管理员密码

首次进入自动进入设置页：至少 8 位、含字母与数字，保存后自动登录。

http://127.0.0.1:8000/memo_login.html
STEP 03

给模型签发 Token

一行命令签发只存哈希的 Bearer Token，写进 MCP 客户端配置即可读写日程。

mcp_server.py --issue-token admin <password>
